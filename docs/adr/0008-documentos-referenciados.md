# 0008. Documentos institucionales referenciados no disponibles

Fecha: 2026-10-06 · Estado: aceptado · Vigencia: hasta 2026-10-24

## Contexto

Los estándares de backend y frontend remiten a otros documentos institucionales (ciclo de versiones, clean code, arquetipo de arquitectura, régimen de no conformidades) que no están disponibles para el proyecto.

## Decisión

Se aplican los dos estándares disponibles (DES-STD-004 y DES-STD-002) completos. Donde remiten a un documento ausente, se usa la práctica general de la industria y se documenta en este directorio cuando la decisión es relevante.

## Consecuencias

- Las remisiones a esos documentos no se pueden auditar contra su texto.
- Si se publican, se revisa el proyecto contra ellos.

## Norma afectada

DES-STD-001, DES-STD-005, DES-ARQ-001 y DES-POL-001
